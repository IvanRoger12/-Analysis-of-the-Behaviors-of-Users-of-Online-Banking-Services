## 🚀 Installation & Utilisation

### Prérequis
- Navigateur moderne (Chrome, Firefox, Safari, Edge)
- Serveur web local (optionnel, fonctionne en file://)

### Démarrage Rapide
1. **Cloner ou télécharger** les fichiers
2. **Ouvrir `index.html`** dans votre navigateur
3. **Profit!** L'application est prête à l'emploi

### Structure des Fichiers
```
ai-dataclean-pro/
├── index.html              # Page principale
├── styles.css              # Styles cyber-punk
├── app.js                  # Application principale

├── chatAI.js             # Chat IA conversationnel

```

## 🎨 Customisation

### Thèmes & Couleurs
Variables CSS personnalisables dans `styles.css`:
```css
:root {
    --primary-cyan: #00ffff;      /* Cyan principal */
    --primary-magenta: #ff00ff;   /* Magenta néon */
    --primary-neon: #39ff14;      /* Vert néon */
    --dark-bg: #0a0a0a;          /* Fond sombre */
    /* ... */
}
```

### Ajout de Langues
Modifier `translations.js` pour ajouter une langue:
```javascript
translations: {
    fr: { /* ... */ },
    en: { /* ... */ },
    es: { /* nouvelles traductions */ }
}
```

### Nouveaux Formats de Fichier
Étendre `dataProcessor.js` avec de nouveaux parsers:
```javascript
switch (fileExtension) {
    case 'parquet':
        data = await this.parseParquet(file);
        break;
    // ...
}
```
